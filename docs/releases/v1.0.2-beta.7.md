## Release description

Copy the following block into the GitHub release description:

```markdown
Athan Time is an offline prayer-time desktop application for Windows, macOS and Linux.

### What's new in beta.7
- Support, suggestions, complaints and log-sharing drafts now use **athantimedotnet@gmail.com**.
- The shipped configuration and fallback recipient are aligned.
- Expanded regression coverage checks the shipped settings, all eight languages, configuration overrides and invalid recipients.
- Updated documentation and rebuilt release downloads for the new beta version.

The app opens drafts in your own email program. Nothing is sent automatically.
Review exported logs before manually attaching and sending them.

### Validation
- All 431 automated tests passed in both Debug and Release on Windows.
- Both solution builds completed without warnings or errors.

### Downloads
- **Windows x64:** use the setup executable to install or update, or extract the portable ZIP.
- **Linux x64 / ARM64:** extract the matching portable ZIP.
- **macOS Intel / Apple Silicon:** extract the matching portable ZIP; these are terminal-launchable payloads, not Finder app bundles.
- **Source ZIP:** for developers building the application.

Application downloads include .NET; no separate .NET installation is needed.
Keep all extracted files together. Normal OS desktop/audio libraries are still required.
For Linux/macOS, run `chmod +x AthanTime.Net` and then `./AthanTime.Net` in the extracted folder.

### Beta limitations
- Windows downloads are unsigned. Windows security features, including Smart App Control, may warn about or block them.
- Linux/macOS ZIPs are cross-published from Windows and require matching-OS desktop testing. Native DEB/DMG installers require matching build hosts.
- Native installation/update/uninstall, tray, audio, login and macOS signing/notarization remain separate validation work.
- Reminders require the app to be running while the computer is awake.

See `SHA256SUMS.txt` for download checksums and `BUILD-INFO.json` for build and automated-test evidence.

This is a **beta prerelease**.
```

## Upload checklist

Upload the seven versioned downloads, `SHA256SUMS.txt`, `BUILD-INFO.json` and
`RELEASE-INFORMATION.md` from `artifacts/releases/v1.0.2-beta.7/` as release assets.
Keep generated binaries out of the source Git repository. The versioned downloads
are Windows setup, five RID-specific portable ZIPs and the reviewed source ZIP.
Use the actual checksums from this build; beta.6 checksums apply only to beta.6.
Exit the app before updating; preserve its existing install folder and profile.
Publishing the GitHub release is a separate user-directed action; local packaging
does not upload files, push refs or change existing GitHub releases.

See [packaging evidence](../PACKAGING.md#support-mailbox-beta7-2026-11-08) and the
[release checklist](../RELEASE-CHECKLIST.md) for validation and native limitations.
