# Athan Time v1.0.2-beta.15

## Release description

```markdown
Athan Time provides prayer times, Athan reminders and Adhkar for Windows, Mac and Linux. It works offline and needs no account.

### What's new

- Easier Windows installation, updates and removal, with a clear message when uninstall finishes.
- Updated Athan and Allahu Akbar recordings.
- Test buttons to try reminders and Adhkar.
- Fixed the next-prayer countdown after changing your computer's date or time.
- Improved layout, checkbox alignment and Linux app icon.
- Easier startup on Mac and Linux, and a suggested city when you first open the app.

### Getting started

Download the file for your computer. On Windows, use Setup. For ZIP downloads, extract all files and follow the included README. No separate .NET installation is needed. Mac users need macOS 15 or newer.

Review your city and reminder settings. Keep the app running and your computer awake for reminders.

This is a beta version. Windows and Mac may show security warnings when opening the app.
```
