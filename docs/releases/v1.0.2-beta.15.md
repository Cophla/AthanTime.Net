## Release description

```markdown
Athan Time provides offline prayer times, Athan reminders and Adhkar for Windows, macOS and Linux.

### What's new
- Windows uninstall now clearly confirms successful removal, including All users installations. Silent uninstall remains unattended.
- Checkbox captions now align vertically with their indicators, including wrapped text and right-to-left layouts.
- First launch uses your supported OS language and 12/24-hour preference and suggests a city from region/time zone. Confirm or change the city before automatic prayer reminders start. Existing settings stay unchanged.
- Optional settings removal: an unchecked checkbox in Windows uninstall, and confirmation helpers for Windows portable, macOS and Linux. Other users and custom recordings are preserved. Run Unix helpers as your normal user before removing the app.
- Windows setup requests graceful exit before updates and opens the app visibly after successful interactive setup. Older versions may need manual Exit once; silent setup skips launch.
- Setup offers Uninstall for an existing Windows installation. Updated apps receive a direct graceful shutdown request, including from the tray. Optional settings-cleanup failures provide Retry, keep remaining settings and continue, or Abort.
- Test buttons for prayer reminders, Adhkar recordings and text Adhkar.
- Updated default Athan and Allahu Akbar recordings; the former bundled Alhamdulillah recording is removed. Custom recordings are preserved.
- Fixed next-Athan countdown updates after changing the PC date/time.
- Clearer About text with clickable project/download links in all eight languages.
- Easier Mac startup with an app bundle and optional .command launcher; detached Linux launchers and optional menu/dependency helpers.
- Corrected Linux menu/dock icon registration. Run Install-Shortcut.sh once from the updated folder, fully exit/reopen the app, and replace an old pinned generic shortcut if needed.
- Every portable package includes a README with simple startup, update and settings-removal instructions; Mac/Linux retain their START-HERE guides. Windows setup also installs the README.
- Windows optional settings cleanup runs in the original user before elevation for All users removal, avoiding the failing desktop-token launch. Start uninstall normally; a Run as administrator launch keeps settings and disables that option.

### Downloads
- Windows x64: Setup installer or Portable ZIP.
- macOS 15+: Intel x64 or Apple Silicon ARM64 Portable ZIP. Extract fully and open Athan Time.app.
- Linux desktop: x64 or ARM64 Portable ZIP. Extract fully and use Launch-Athan-Time.sh.
- All application downloads include .NET 11; no separate .NET installation is needed. Source builds require the .NET 11 SDK.

City suggestions are not exact location detection. The app stays offline; automatic GitHub version checking is not included.
For Mac/Linux updates, quit the app before replacing files. Settings are kept by default when uninstalling.

### Verification and beta limits
Initial testing was reported as looking fine by the project owner on November 17. The scope and platforms of that report were not specified; it does not replace the native checks below.
The November 17 Debug and Release checks on Windows x64 passed 528 tests in each, with one symbolic-link permission skip and zero build warnings/errors. These include uninstall completion guards, cleanup and checkbox alignment in all eight languages/themes, including wrapped three-state text. English/Arabic captures were inspected during the November 16 alignment work. BUILD-INFO.json identifies the evidence. Native Windows uninstall/UAC and Linux/macOS desktop rendering still need matching-host checks.
Five portable payloads are checked for bundled runtime, native architecture, content hashes and executable permissions. See BUILD-INFO.json and SHA256SUMS.txt for the actual package evidence.
Native install/update/uninstall, UAC cleanup identity, Finder/Gatekeeper, Linux desktop, audio and tray/login checks still require matching-OS verification. Cross-publishing is not native certification; native DEB/DMG creation requires matching hosts.
Windows output is unsigned and may be blocked by Smart App Control. macOS output is unsigned/not notarized.
The supplied recordings' upstream redistribution rights remain unverified; review THIRD-PARTY-NOTICES.md before public distribution.
Reminders require the app to be running while the computer is awake.

Project: https://github.com/Cophla/AthanTime.Net
Downloads: https://github.com/Cophla/AthanTime.Net/releases
Support: athantimedotnet@gmail.com

This is a beta prerelease.
```
